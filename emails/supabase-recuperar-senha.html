Vamos criar uma senha nova?

Recebemos um pedido para redefinir a senha da conta {{ .Email }} na GN Coleciona.

Clique no botão abaixo para escolher uma senha nova. Sua coleção continua do jeito que você deixou.
Criar senha nova
Se o botão não abrir, copie este endereço e cole no navegador:
{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=recovery&next=/login/nova-senha
O link vale por 1 hora e só pode ser usado uma vez. Se não foi você quem pediu, é só ignorar este e-mail: sua senha continua a mesma.
